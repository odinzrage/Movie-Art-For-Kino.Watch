# 🎬 Movie Art for Kino.Watch

Расширение для Kino.Watch для поиска горизонтальных постеров фильмов и сериалов.

## ✨ Особенности

- 🖼️ Поиск горизонтальных изображений (Wide Posters).
- 🎞️ Поддержка изображений для карточек фильмов и сериалов.
- ⚡ Использование прямых ссылок на изображения.
- 🧹 Отказ от лишних попыток загрузки вертикальных постеров.
